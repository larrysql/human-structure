# 人的结构 · Human Structure

一个关于人类心理、认知、情绪、欲望、关系、行为与人生结构的长期研究项目。

## 核心问题

一个人为什么会成为现在的自己？

## 核心假设

人的许多困境并不是孤立发生的。

它们可能来自某些稳定的心理、认知、关系与行为结构。

本项目尝试从真实的人生困境出发：

> 困境 → 观察 → 分类 → 建模 → 验证 → 理论 → 写作

## 核心结构

1. 自我
2. 认知
3. 情绪
4. 欲望
5. 关系
6. 行为
7. 习惯
8. 身份
9. 人生
10. 重构

## 项目目标

建立一套能够解释真实人生困境的“人的结构”知识体系。
